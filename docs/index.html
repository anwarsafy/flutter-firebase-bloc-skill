01

Clean Architecture

Domain stays pure Dart. Widgets never talk to Firebase.

02

Single-state BLoC

One state, an enum status, copyWith. A failed refresh keeps the data on screen.

03

Offline-first Firestore

Ordinary writes are not awaited. The UI listens for pending writes.

04

Rules that deny

No client writes to role, plan, or isPro. No scraping a collection with list.

05

English and Arabic

RTL from the first screen. No raw exception strings in the interface.

06

CI included
